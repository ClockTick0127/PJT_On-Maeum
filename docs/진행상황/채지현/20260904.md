### 2. HDFS 적재 잡 병합 후 점검 (`feature/infra/hdfs` → develop 병합 완료)

- 어제 병합된 `infrastructure/hdfs/` (compose + loader) 코드를 브릿지·리플레이 시뮬레이터와 교차 확인
- 확인된 사항
  - 리플레이 시뮬레이터 → 로더: 토픽(`power-raw`)·스키마(`house, device, ts, power_w`) 일치, 바로 적재됨
  - **브릿지 → 로더: 토픽 불일치.** 브릿지는 `power.raw.v1`로 발행, 로더는 `power-raw`만 구독 → 현재 MQTT 경로(시뮬레이터·실물 센서) 데이터는 HDFS에 적재되지 않음
  - 메인 compose가 토픽 자동 생성을 꺼둬서 `power-raw`는 수동 생성 필요. 저장소에 생성 스크립트 없음
  - at-least-once 특성상 재시작 시 파일 단위 중복 가능 → Silver 단계에서 `(house, ts)` 기준 중복 제거 필요. Spark 배치 담당에게 인계할 내용
