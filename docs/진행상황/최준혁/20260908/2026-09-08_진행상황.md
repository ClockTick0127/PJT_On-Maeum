* **경량 웹 컨트롤러 서버 신규 구축 (`web_server.py`)**:

### (2) 10초 피크 시연 타임라인 설계 (`simulator.py`)

NILM 모델의 실시간 이벤트 감지 및 프로젝트 시연을 위해, 시작 10초 시점에 3,000W 이상의 고전력 피크를 발생시키는 타임라인 시나리오를 구축했습니다.

```text
[ 유효전력 (Active Power) 타임라인 추이 ]

 4,000W |
        |                 +-----------------------+ (전기포트 + 인덕션 동시 가동: 3,350~3,590W)
 3,000W | - - - - - - - - | - - - - - - - - - - - | - - - - - - - - - - - [ 3,000W 피크 경보 임계치 ]
        |                 |                       |
 2,000W |                 |                       |         +-------------+ (인덕션 단독: 약 1,650W)
        |                 |                       |         |             |
 1,000W |                 |                       |         |             |
        |  (대기: ~60W)   |                       |         |             |  (대기전력 복귀: ~60W)
    0W  +-----------------+                       +---------+             +-----------------------+
        0s               10s                     31s       45s           46s                     60s
```

* **T+01s ~ T+09s (평상시 대기 상태)**:
  - 기저부하(상시 대기전력 약 50~65W, 역률 0.92~0.95)만 소비
* **T+10s ~ T+30s (피크 전력 발생)**:
  - 전기포트(1,700W)와 인덕션(1,600W) 동시 기동
  - **합산 전력 3,350 ~ 3,590W 도달 (3,000W 초과 피크 경보 발령)**
* **T+31s ~ T+44s (피크 전력 해소)**:
  - 전기포트 물 끓음 완료로 자동 정지
  - 인덕션 단독 가동 유지 (약 1,650W, 역률 0.93)
* **T+45s ~ T+60s (정상 대기 복귀 및 시연 완료)**:
  - 인덕션 조리 완료로 정지
  - 평상시 대기전력(약 60W) 상태로 복귀 후 60초 도달 시 무오류 자동 종료
