실험 구성 요약

Validation set 단독, 6종 수동 가전(포트·인덕션·다리미·전자레인지·헤어드라이기·청소기) 보유 15가구 × 32채널. 가구별 31일을 Train 19일 / Val 5일 / Test 7일로 시간분할, 임계값·병합 파라미터는 Val에서만 선정하고 Test는 1회 측정. 모델은 채널별 TCN(본선) + Stats-MLP(경량 대조군). 상세는 MVP실험계획.md·회고 문서 참조.

03

5단계 — 대상 가전 무사용 판정 (근사 반사실 스트레스 테스트)

이 절은 "부재 감지" 검증이 아니다 "자연 무사용일"은 사람이 부재한 날이 아니라 여섯 가전을 쓰지 않은 날이고, "합성 무사용"은 메인에서 가전 전력을 차감한 반사실 신호다. 재실·안전 정답이 없으므로 서비스 성능(거짓 안심·거짓 경보)을 말할 수 없다. 아래 세 측정은 분모가 서로 다르므로 한 범위로 묶지 않는다 (자연 = 채널-일 29건 · 가전 합성 = 채널-일 195건 · 가구 합성 = 가구-일 89건). 용도는 가전 특이도의 약점 진단이다.

세 가지 무사용 측정 — 분모가 다른 세 숫자

무사용을 무사용으로 판정한 비율 · 점선 = 계획 당시 목표 95% (서비스 목표가 아닌 개발 목표)

실측 (6종 미사용일 — 재실 여부 불명) 합성 (반사실 신호 — 다른 활동은 남음)

15가구 × Test 7일: 6종 전부 차감한 합성일의 판정

초록 = 무사용 판정 · 빨간 테두리 = 사용으로 오판 · 원래 사용이 없던 날은 제외 · 합성 신호이므로 실제 부재 아님

D1D2D3D4D5D6D7 H022FQF H023FQQ H026FQQFQQQ H027QFQQQQQ H029QQF H057FFF H069FFFFFFQ H070FFQFFQF H077QQQQQQQ H082QFFFQQF H083FFQQQQQ H098FFQFFFF H102QFFFFFF H103QQQQFQQ H105FFFFFFF

D일 연속 무사용 규칙을 합성일에 적용하면: D=1 → 13/15가구 · D=2 → 8/15 · D=3 → 5/15 트리거. H077·H103·H027은 깨끗하고, H105·H069·H098·H102는 만성 오판 — 배경 부하가 복잡한 집(인덕션·김치냉장고 다수)과 일치. D 규칙은 확정하지 않는다: D=1/2/3 · 시간대 · rolling 24/48h를 누락률·월간 확인 후보 수·지연 분포(p90)로 비교해야 하며, 초기 기획 "수 시간 내 감지" 대비 D=2는 목표 후퇴다.

해석의 한계 합성 무사용은 6종 타겟 가전만 차감한다 — 밥솥 취사·세탁기·조명·충전기 등 사람의 다른 활동은 신호에 그대로 남는다. 따라서 47.2%는 "재실 중이지만 6종만 안 쓴 날"의 판정률이고, 실제 부재일의 판정률이 아니다. 자연 무사용일 역시 재실 여부를 모른다. 이 실험으로 실제 부재 감지율을 추정하지 않는다(이전 판의 "47~86% 구간" 표현 철회). 유효한 결론은 하나 — 모델이 배경 부하(44%)와 유사 가전(36%)에 발화하는 특이도 약점이 있다.
설계 가설: NILM 단독이 아니라 총량과의 하이브리드 "총 전력이 평탄하면 무사용"이라는 가정은 합리적이지만 검증되지 않은 가설이다. 총량 기준선 / 서브미터 oracle / NILM / NILM+총량을 동일 지표로 비교하는 것이 A안 2단계의 핵심 실험이며, 여기서 NILM이 총량보다 유의미하게 낫지 않으면 차별점 논리를 수정해야 한다. 참고: 완벽한 6종 감지기를 가정해도 대상 가전 무사용일은 16/105 — D=1 규칙이면 월 약 4.6회의 "확인 후보일"이 생긴다 (거짓 경보 여부는 판단 불가).
04

남은 3주 — A안 (검수자·AI 파트 합의, 09-02)

RTX 4070 Laptop으로 추론은 해결됐고(재추론 8.5분, CPU 대비 25배) 학습은 32채널 7.5시간(CPU)이 병목이었다. 그러나 검수 결론대로 GPU 확장보다 평가 체계 수정과 cross-house 검증이 먼저다 — 잘못된 지표를 빠르게 반복하는 것이 더 큰 위험이다. H200은 게이트 통과 이후의 가속 수단으로 둔다.

A안 4항목

① 평가 오류 수정 (완료) — 1:1 매칭 재검산, 가구-일 재집계 + bootstrap CI, 용어·과장 교정, 코드 저장소 반영(scripts/)
② 핵심 가설 검증 — 총량 기준선 vs oracle vs NILM vs 하이브리드 동일 지표 비교 · 16가구 cross-house 스모크(leave-one-house-out, 개발 결과 표기) · "분전반 신호에서 신규 가구의 수동 가전 사용 징후를 추출할 수 있는가"
③ AI 산출물 확정 — 체크포인트 · 입력 특성(4특징·1Hz·299초)·샘플링 규격 · 추론 API 입출력 명세 · 가전별 예측 확률/이벤트 출력 · 한계·적용 조건 문서
④ 후속 과제 이관 — 110가구 최종 검증(미열람 상태에서 가구 단위 잠금 분할) · H200 스윕 · 멀티라벨 · 실제 부재 검증(재실 정답) · 알림 규칙·하드웨어(P/Q/PF 획득 가능 계측 IC)·서비스 기능

AI 파트의 공식 결론 문장 분전반 총량으로부터 수동 가전 사용이라는 활동 대리지표를 추출하는 AI 파이프라인을 구현하고, 동일 가구 및 제한적인 cross-house 환경에서 기술 가능성을 검증했다.
