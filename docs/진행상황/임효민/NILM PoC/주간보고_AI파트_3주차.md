## 슬라이드 3 — EDA에서 얻은 설계 근거 (데이터가 기획을 바꾼 것)

- **안부 신호 후보 가전 순위가 바뀜**: 전자레인지 > 청소기 > 헤어드라이기 > 포트 > 인덕션. **밥솥은 보온 모드가 지배**(ON 중앙 45W)해 통째로는 부적합 → 취사 이벤트 분리 필요
- **미계측 부하 평균 65%** (29~86%): 총 전력 "완전 분해"가 아니라 **타겟 가전 이벤트 분류**로 문제 재정의
- **수동/자동 가전 구분자 = 야간(02~05시) 사용률**: 수동 0~2.4% vs 자동 12~27%
- **이벤트 정의가 모델보다 큰 레버리지**: 인덕션에 세션 병합(10분)을 적용하자 가장 어려운 가전이 최고 성적(recall 0.95)
- **샘플링 스펙 근거**: 포트·전자레인지 1kW급 스텝은 1Hz로 충분, 모터/저항 구분(돌입 ×1.55 vs ×1.00)은 5~10Hz 필요 → 수집 5~10Hz / 모델 1Hz

## 슬라이드 4 — 외부 검수와 정정 (숨기지 않고 발표할 것)

검수에서 지적된 오류와 조치:

| 지적 | 조치 |
| --- | --- |
| "96% 통과"는 채널-일 가중 수치 | 가구-일 93.3% + 가구 bootstrap 신뢰구간으로 교체, "통과" 철회 |
| "거짓 안심 2.6%" 용어 반전 | 서비스 용어(거짓 안심·부재 감지) 전부 제거 → "대상 가전 무사용" |
| 이벤트 매칭 중복 계산(8채널 모순) | greedy 1:1 매칭 재검산 + 단위 테스트 5건 |
| 분모 다른 지표 혼합("47~86%") | 4개 지표 분리, 합성 실험은 스트레스 테스트로 격하 |
| 코드 재현성 부족 | scripts/ 11파일 + README, 구/신 평가 구분 |

**3 endpoint 분리**: ① 기술(가전 이벤트) ② 대리지표(무사용일) ③ 서비스(실제 부재) — 공개데이터로는 ①②만 답할 수 있음. 이번 주 결과는 ①②.

## 슬라이드 5 — 핵심 가설 검증 (진행 중)

**Q1. NILM이 총량 방식보다 나은가?** — 지지됨 (결정적이지 않음)
- NILM(임계값 Val 고정) Balanced acc 0.858 vs 총량 규칙 사후 최적 0.785, 사용일 recall 0.966 vs 0.820
- 차이는 저전력 사용일(짧은 드라이기·청소기)에서 발생 — 총량은 못 잡고 NILM은 잡음
- 무사용일 16건 중 4건은 모든 방법이 "사용"으로 판정 → 총량이 평탄하지 않은 무사용일(다른 가전 사용) = **6종으로 활동을 대표하는 대리지표 자체의 한계**

**oracle(완벽 감지 가정)이 알려준 것**: 6종 전략만으로도 가구·월 4.6 확인 후보일, Test 7일 내 D=2 연속 무사용 4/15 가구 → 담당자 처리량은 모델이 아니라 **전략의 후보 빈도**가 결정

**Q2. 학습에 없던 가구에서도 되는가? (cross-house, 사업 성립 게이트)** — 32 fold 중 11 완료
- 초기 관찰: 개인화 대비 대체로 낮음(예: 포트 H029 recall 0.25 vs 0.75), 일부 역전 — **결론 보류, 완료 후 보고**

- **하드웨어**: 모델 입력이 유효·무효전력·역률·전류 4특징 → **SCT-013 전류 클램프 단독으로는 불가**. 전압 동기 샘플링 또는 전력계측 IC(HLW8032, ADE7753 계열) 필요. 수집 5~10Hz 권장
