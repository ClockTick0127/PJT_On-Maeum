> 기준일: 2026-09-02 (0901·0902 검수 반영 정정판) / 작성: AI 파트
> 정정 이력은 문서 끝 §6 참조. 이전 판(08-30)의 "서비스 수준 확인", "거짓 안심 2.6%", "부재 감지 47~86%" 표현은 철회.

## 한 줄 요약

분전반 한 지점의 전력 신호에서 **수동 가전 사용이라는 활동 대리지표를 추출하는 AI 파이프라인을 구현하고, 동일 가구 환경에서 기술 가능성을 검증했다.** 신규 가구 배포(cross-house), 실제 부재·위험 감지, 현장 센서 호환성은 **아직 검증되지 않았다.** 산출물 명칭은 "서비스 MVP"가 아닌 **"NILM 기술 PoC"**로 제한한다.

무사용일 recall의 신뢰구간이 전 범위인 것은 무사용일 16건이 소수 가구에 몰려 있기 때문 — **통계적으로 주장할 수 있는 것이 없다.** 가구 최저 정확도 H057 0.43.

### 합성 무사용 실험 — "근사 반사실 스트레스 테스트"로 격하

메인에서 가전 채널을 차감한 합성 신호는 실제 부재가 아니며(사람의 다른 활동이 남음), 실제 부재 근거로 사용하지 않는다. 결과는 가전 특이도의 약점을 보여주는 진단 용도: 가전 단위 무사용 판정 52.3%(채널-일), 6종 전부 차감 가구-일 47.2%. 오탐 원인 분해: 배경 부하 44% / 유사 가전 혼동 36% / 차감 인공물 21%.

### 데이터가 가르쳐준 것 (유효)

- 안부 신호 후보 가전 실측 순위: 전자레인지 > 청소기 > 헤어드라이기 > 포트 > 인덕션. 밥솥은 보온 모드 때문에 통째로는 부적합
- 미계측 부하 평균 65% → "완전 전력 분해"가 아닌 "타겟 가전 이벤트 분류"로 문제 재정의
- 시각 루틴은 약함(첫 사용 ±1.9~7h) — 단, 31일만으로 루틴 강도를 단정하지 않는다
- 이벤트 정의(세션 병합)가 모델 구조보다 큰 성능 레버리지 (인덕션 실증)
- 완벽한 6종 감지기를 가정해도 **대상 가전 무사용일은 16/105**로, D=1 규칙이면 월 약 4.6회의 "확인 후보일"이 생김 (실제 거짓 경보 여부는 판단 불가)

## 3. 남은 3주 계획 — A안 (검수자·AI 파트 합의)

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 1. 평가 오류 수정 | 1:1 매칭 · 가구-일 재집계 · 용어·과장 교정 · 코드 저장소 반영 | 완료 (09-02) |
| 2. 핵심 가설 검증 | 총량 기준선 vs NILM · 16가구 cross-house 스모크 · "신규 가구의 수동 가전 사용 징후를 추출할 수 있는가" | **기준선 완료(09-02)**, cross-house 진행 중 |
| ↳ 2-① 기준선 결과 | oracle: 6종 전략 자체가 가구·월 4.6 확인 후보일, 7일 내 D=2 연속 무사용 4/15 가구 · 총량 규칙 Val 선정 실패(무사용일 5건) → Test 사후 상한 p95≥500W: acc 0.810/BalAcc 0.785 · NILM(Val 고정): acc 0.933/BalAcc 0.858 · 무사용일 recall은 모두 0.750(같은 4건: 총량이 평탄하지 않은 무사용일) · scripts/baselines.py, baselines_sweep.py | 개발 결과 |
| 3. AI 산출물 확정 | 체크포인트 · 입력 특성·샘플링 규격 · 추론 API 입출력 명세 · 가전별 예측 확률/이벤트 출력 · 한계·적용 조건 문서 | 진행 예정 |
| 4. 후속 과제 이관 | 110가구 최종 검증 · H200 스윕 · 멀티라벨 · 실제 부재 검증 · 알림 규칙·하드웨어·서비스 기능 | 문서화만 |

원칙: Validation 16가구는 EDA·모델 선정에 전부 쓰였으므로 **legacy 개발 세트** — holdout을 만들 수 없고, 모든 수치는 "개발 결과"로 표기. D 규칙(D=1/2/3, rolling, 시간대)은 후보 비교표만 남기고 확정하지 않는다. 초기 기획의 "수 시간 내 감지" 대비 D=2는 목표 후퇴임을 명시.

## 4. 용어 사전

### 개념

| 용어 | 설명 |
| --- | --- |
| NILM | 분전반 한 지점의 총 전력 신호를 분해해 개별 가전의 상태를 추론하는 기술 |
| 수동/자동 가전 | 사람이 켜야 하는 가전(활동 대리지표) vs 스스로 도는 가전(걸러낼 대상). 구분자는 야간(02~05시) 사용률 |
| 미계측 부하 | 서브미터 없는 부하(조명·충전기 등). 메인 전력의 29~86% |
| 다변량 특징 | 유효전력 + 무효전력 + 역률 + 전류. 유효전력만으론 분류 실패 실증. **현장 센서(SCT-013 단독)로는 획득 불가 — 전압 동기 샘플링 또는 계측 IC 필요** |
| 돌입전류(오버슈트) | 모터 기동 시 순간 전류(냉장고 ×1.55 vs 저항성 ×1.00). 수집 5~10Hz 근거 |

### 모델·학습

| 용어 | 설명 |
| --- | --- |
| Seq2Point | 윈도우 입력 → 중심 시점 예측 구조 (데이터셋 제공 베이스라인) |
| TCN | dilated 합성곱 CNN. **2가전 제한 비교**에서 최고 성능이라 채택 — 구조 선택보다 평가 정의·cross-house가 우선 |
| Stats-MLP | 윈도우 통계량만 쓰는 초경량 모델. 경량 필터·스트레스 테스트용 |
| 윈도우 | 299초 × 1Hz × 4특징. 라벨은 가전 채널 >50W |
| 세션 병합 | 짧은 ON/OFF 반복을 하나의 사용 세션으로 묶는 이벤트 정의 (인덕션 10분) |
| 균형 샘플링 / pos_weight | ON 0.3%대 불균형 대응 |
| cross-house / leave-one-house-out | 학습에 없던 가구에서 측정. **사업 성립 게이트** |
| 멀티라벨 통합 모델 | 메인 신호 → 6가전 상태 동시 출력. 후속 과제 |

### 평가

| 용어 | 설명 |
| --- | --- |
| 개발 결과 | 16가구 legacy 개발 세트에서 나온 모든 수치의 표기. 최종 일반화 근거로 쓰지 않음 |
| train/val/test 시간분할 | 19/5/7일. 임계값은 val에서만. 단, Test도 모델·병합 전략 결정에 참조되어 **이미 개발 세트화** |
| 1:1 이벤트 매칭 | greedy, onset ±60초 또는 IoU ≥ 0.3, 이벤트당 1회 매칭. 구 방식(30% 겹침)은 조각 중복 계산 결함 |
| 사용일 recall / 무사용일 recall | 가구-일 기준. 후자가 "확인 후보 감지" 능력이며 현재 CI [0, 1] |
| 가구 block bootstrap | 가구 단위 재표집 신뢰구간 — 같은 가구의 날·채널은 독립이 아님 |
| 확인 후보일 | 대상 가전이 하루 사용되지 않은 날. **거짓 경보인지는 재실 정답 없이 판단 불가** |
| 합성 무사용 | 메인 − 가전 채널로 만든 근사 반사실 신호. 스트레스 테스트용, 실제 부재 아님 |
| ~~거짓 안심 / 거짓 경보 / 부재 감지~~ | 서비스 endpoint 용어 — 재실 정답 있는 실험에서만 사용 |
