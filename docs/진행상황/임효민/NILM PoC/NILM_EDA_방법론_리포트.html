데이터 파이프라인: 769GB를 풀지 않았다

VS.zip(68GiB, 해제 시 769GB)을 전체 압축 해제하는 대신 zip에서 직접 스트리밍하여 131개 채널 전부를 1Hz 캐시(총 ~7GB)로 변환했다. 6-워커 병렬로 61분, 오류 0건. 디스크 쓰기 약 630GB를 절약했고, 이 단일 머신 기록(131채널/61분)은 추후 Spark 분산 전처리 실험("왜 Spark인가")의 대조군 수치로 그대로 쓸 수 있다.

NILM 난이도 실측

라벨된 가전이 설명하지 못하는 메인 전력 — 평균 65%

가구별 미계측 부하 비율 = 1 − (서브채널 합 ÷ 메인 전력)

서브미터가 없는 부하(조명·비데·공유기·충전기 등)가 메인 전력의 29~86%를 차지. → 총 전력을 가전별로 "완전 분해"하는 회귀 접근은 이 데이터에서 성립하기 어렵고, 타겟 가전의 이벤트 감지·분류가 목적에 맞는 문제 정의다.

이벤트 충돌률 — Event Detection 난이도

수동 가전 이벤트 시작 ±5초 안에 다른 채널에서 100W 이상 변화가 있는 비율은 가구 중앙값 4.8%로 낮다. 단, 인덕션+김치냉장고를 함께 쓰는 H069는 31.8%, H029도 21%로 가구 편차가 크다 — 동시 이벤트 분리는 엣지 케이스로 처리하되, 일 단위 집계가 오차를 흡수한다.

RQ0 분산 전처리 — 대조군 확보

단일 머신 스트리밍 131채널/61분 실측 — Spark 2/4/8 워커 비교 실험의 기준선으로 사용.

RQ2 가구 간 일반화 — 다음 실험

포트(CV 0.11)·다리미·인덕션이 유망, 에어프라이어(1.17)는 불리. N−1 가구 학습 → 미학습 가구 평가(leave-one-house-out)가 다음 단계.
