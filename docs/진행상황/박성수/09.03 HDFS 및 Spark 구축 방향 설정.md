# Spark & HDFS 학습 현황

대용량 전력 사용 데이터를 효율적으로 처리하기 위해  
HDFS와 Spark 기반의 분산 데이터 처리 환경을 학습하고 구축한다.

- 현재는 **컴퓨터 2대를 활용한 분산 환경 구성 및 동작 검증**을 진행
- PC 4~6대를 연결하여 HDFS 분산저장 및 Spark 데이터 분산처리 환경 구축 예정

<br />

## 현재 학습 내용

### HDFS

- NameNode / DataNode 구조 학습
- HDFS 분산 저장 방식 이해
- Block 및 Replication 개념 학습
- 다중 노드 HDFS 환경 구성 및 파일 저장 테스트

### Apache Spark

- Driver / Executor 구조 학습
- Spark Master / Worker 구조 이해
- DataFrame 기반 데이터 처리 학습
- Spark를 이용한 HDFS 데이터 읽기 및 처리 테스트

<br />

## 분산 환경 구성

현재 컴퓨터 2대를 이용하여 Spark 및 HDFS 클러스터를 구성하고 있다.

```text
PC 1
├─ HDFS NameNode
├─ HDFS DataNode
├─ Spark Master
└─ Spark Worker

PC 2
├─ HDFS DataNode
└─ Spark Worker

... 확장 예정
```
