# 2026-09-07 진행상황

## 목표

- NILM 전력 데이터 전처리를 위한 로컬 분산 환경의 기본 구성 완료
- HDFS 분산 저장 및 Spark 분산 처리 구조가 정상적으로 동작하는지 검증

## 진행 내용

### 1. 공용 계정 및 네트워크 구성

- 프로젝트 공용 Google 계정 생성
- Tailscale 네트워크 구성
- 총 4대의 장비를 동일한 Tailscale 네트워크에 연결
- 로컬 네트워크 제약이 있는 환경에서도 각 장비 간 TCP 통신이 가능하도록 구성

### 2. HDFS 클러스터 구성

- HDFS 연결 완료
- NameNode와 DataNode 역할 분리
- 4대의 컴퓨터 모두 DataNode 역할 수행
- 각 노드가 분산 저장에 참여하도록 구성

### 3. Spark 클러스터 구성

- Spark 연결 완료
- Master와 Worker 역할 분리
- 4대의 컴퓨터 모두 Spark Worker 역할 수행
- 각 Worker가 분산 연산에 참여하도록 구성

### 4. 네트워크 및 접근 설정

HDFS 저장과 Spark 연산을 위해 필요한 설정 진행

- 장비별 방화벽 설정
- SSH 연결 설정
- 클러스터 내부 통신을 위한 포트 및 접근 설정
- Tailscale IP 기반 노드 간 통신 확인

### 5. 분산 저장 및 처리 테스트

소규모 데이터를 활용하여 테스트

1. 데이터를 HDFS에 업로드
2. 여러 DataNode에 데이터가 분산 저장되는지 확인
3. Spark에서 HDFS 데이터를 읽어 연산 수행
4. 여러 Worker가 작업에 참여하는지 확인
5. 연산 결과가 정상적으로 생성되는지 확인

## 결과

- HDFS 분산 저장 정상 동작 확인
- Spark Master-Worker 구조 정상 동작 확인
- 여러 장비를 이용한 Spark 분산 연산 확인
- Tailscale 환경에서 HDFS 및 Spark 통신에 문제가 없음을 확인
- 향후 대용량 데이터 전처리를 위한 기본 분산 환경 구축 완료
