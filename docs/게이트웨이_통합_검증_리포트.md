# API Gateway 통합 검증 리포트 (0914, 채지현)

로컬 환경에서 게이트웨이(:8080) 경유로 iot-device-service(:8083), monitoring-service(:8082)를
실측 검증한 결과. 구성: `IOT_DEVICE_SERVICE_URL=http://localhost:8083` (Spark UI의 8081 점유로 포트 이동
— 계약 초안의 포트 배정표 참조).

## A. 서비스 라우팅 — ✅ 통과

| 검증 | 방법 | 결과 |
| --- | --- | --- |
| /api/devices/** → iot-device-service | 게이트웨이 경유 vs 직접 호출 응답 비교 | ✅ 동일 응답 (가구 목록 JSON 일치) |
| /api/monitoring/** → monitoring-service | SSE 연결로 겸증 (B 참조) | ✅ |

## B. SSE 프록시 통과 — ✅ 통과 (핵심 검증)

**우려했던 문제**: 게이트웨이가 응답을 버퍼링하거나 read timeout으로 스트림을 절단하는 것.

**방법**: 게이트웨이 경유로 `/api/monitoring/stream`을 구독한 채 5분(310초) 유지.

**결과**:
- 연결 유지 **310초** — 게이트웨이가 스트림을 끊지 않음 (`response-timeout=-1` 라우트 설정이 실전에서 유효)
- 모니터링 서비스의 keep-alive 하트비트 **13건**을 버퍼링 없이 즉시 수신 (~24초 간격)
- 종료는 테스트 타이머(310s timeout)에 의한 것 — 게이트웨이·서비스 측 절단 없음

**배포 시 주의**: Nginx가 앞에 붙는 EC2 환경에서는 `proxy_buffering off; proxy_read_timeout` 설정이
추가로 필요 — 동일 테스트를 배포 환경에서 재실행해야 함 (nginx 담당과 협업 항목).

## C. JWT 검증 (보안 스위치 on) — ✅ 통과

`APP_SECURITY_ENABLED=true`로 게이트웨이 재기동 후:

| 케이스 | 기대 | 실측 |
| --- | --- | --- |
| /actuator/health (허용 경로) | 200 | ✅ 200 |
| 토큰 없이 /api/devices/** | 401 | ✅ 401 |
| 위조 토큰(Bearer not-a-real-token) | 401 | ✅ 401 |
| 토큰 없이 SSE /api/monitoring/stream | 401 | ✅ 401 |
| **유효 토큰(nilm-smoke, client_credentials)으로 기기 API** | **200** | **✅ 200 (가구 목록 정상 반환)** |

- 게이트웨이의 1차 검증(토큰 유효성) 동작 확인. 역할(ADMIN) 인가는 각 서비스 담당 — 설계 의도대로
- 해피패스는 keycloak-auth 파트가 realm 임포트에 준비해둔 `nilm-smoke` 스모크 클라이언트로 검증
  (시크릿은 realm JSON의 env 참조 → `local/.env`의 `NILM_SMOKE_CLIENT_SECRET`)

## D. 검증 중 발견·해결한 환경 이슈 (팀 공유)

1. **postgres 볼륨-비밀번호 불일치**: 볼륨이 과거 비밀번호로 초기화돼 `.env`의 값과 다름.
   `POSTGRES_PASSWORD` env는 볼륨 최초 생성 시에만 적용 → **local/.env를 실제 볼륨 비밀번호에 맞춰 수정**하고
   Keycloak 컨테이너 재생성으로 해결
2. **keycloak_db 누락**: 볼륨이 `01-create-databases.sql` 개정 전에 생성돼 keycloak_db·analysis_db 없음
   → 수동 생성(`CREATE DATABASE keycloak_db;`)으로 해결. **볼륨 리셋 없이 팀원 각자 겪을 이슈** —
   근본 해결은 볼륨 리셋(데이터 소실 감수) 또는 이 명령 문서화
3. **8081 포트 충돌**: Spark Master UI 점유 → iot-device-service를 8083으로 이동해 검증
   (포트 배정표 확정 필요 — 계약 초안 §4)

## 결론

게이트웨이 MVP 검증 항목 **전부 통과**: 라우팅 / SSE 5분 유지 / JWT 거부(무토큰·위조) / JWT 해피패스(유효 토큰 200).
남은 항목은 **배포(Nginx) 환경에서의 SSE 재검증** 1건뿐 (nginx 담당과 협업).
